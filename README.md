# DocumentVerificationSystem
A secure Document Verification System that enables users to upload documents, track verification status, and allows authorized administrators to review and verify submitted documents.

## 1. Project Objective
To develop a secure web application that allows users to upload documents and enables authorized reviewers to verify them through a structured verification workflow.

## 2. User Roles
- User: Upload documents and view verification results.
- Admin/Reviewer: Review submitted documents and update their verification status.

## 3. Core Features
- User registration and login
- Secure document upload
- Document metadata storage
- Verification workflow
- Admin dashboard
- Verification history and audit logs

## 4. Technology Stack
- Frontend: HTM, CSS and Javascript
- Backend: Node.js and Express.js
- Database: MySQL
- Optional AI: Google Gemini API and ollama
- Version Control: Git and GitHub

## 5. Verification Statuses
- Pending
- Under Review
- Verified
- Rejected
- Requires Manual Review

## 6. Initial Development Goal
Build one complete workflow: a user logs in, uploads a document, the backend validates and stores it, the reviewer examines it, and the user can view the resulting status.
